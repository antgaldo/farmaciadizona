# 🏥 Farmacia di Zona

Un'applicazione web per la ricerca, la consultazione e la geolocalizzazione delle farmacie di turno e dei servizi farmaceutici sul territorio.

---

## 📌 Descrizione

**Farmacia di Zona** nasce per offrire ai cittadini uno strumento rapido ed intuitivo per individuare le farmacie aperte, i turni festivi/notturni, gli orari di apertura e le indicazioni stradali in tempo reale.

---

## ✨ Funzionalità Principali

- 📍 **Mappa Interattiva e Geolocalizzazione**: Individua rapidamente le farmacie più vicine alla tua posizione.
- 🕒 **Farmacie di Turno**: Filtra facilmente per visualizzare le farmacie aperte o in turno notturno/festivo.
- 📞 **Scheda Dettaglio**: Trova numeri di telefono, indirizzi, orari e servizi offerti da ciascuna farmacia.
- 🔍 **Ricerca per Zona**: Cerca per comune, indirizzo o nome della farmacia.

---

## 🛠️ Tecnologie Utilizzate

- **Frontend**: HTML5, CSS3, JavaScript
- **Mappe & Geolocalizzazione**: Leaflet / OpenStreetMap / Google Maps API
- **Tooling & Build**: Node.js, npm / Vite
